Chess Wager — install
=====================

Correct path after install MUST be:

  wp-content/plugins/chess-wager/chess-wager.php

If WordPress says "Plugin file does not exist":

1. Delete any leftover chess-wager folder
2. Upload this zip via Plugins → Add New → Upload
3. Activate "Chess Wager"

Then:

1. Open Chess Wager in the left WP menu
2. Fill in every URL where the dApp is hosted, one per line
   Example:
     https://chess.voodootoken.com
     https://chess-wager.vercel.app
   First line = the invite link players should share
3. The Vercel dApp already knows this site is https://voodootoken.com/ — no extra env var needed
4. Optional: also put [chess_wager] on a WordPress page

The plugin stores each game id, both wallet addresses, and every signed move.
If a player loses internet or refreshes, they reopen the same game link.

Do NOT unzip on your PC and upload only some files.
Do NOT upload only the dApp dist folder — that cannot remember who is playing.
